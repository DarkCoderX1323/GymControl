# GymControl

Sistema de gestión para gimnasios desarrollado en Java.

## Tecnologías

- Java
- Swing
- MySQL
- JDBC
- Maven
- Apache POI
- MVC
- DAO

## Funcionalidades

- Login de usuarios
- Gestión de socios
- Gestión de membresías
- Registro de pagos
- Control de asistencia
- Reportes Excel

## Estado

Fase de desarrollo académico.
